# LM Concept — Site

Site institucional do ateliê automotivo LM Concept (15 anos).

- Página única, sem dependências: abra `index.html` no navegador.
- Imagens e logos já estão embutidos no arquivo.
- Fontes carregadas do Google Fonts (Saira e Hanken Grotesk).

## Antes de publicar

No final do `index.html`, preencha a variável `WA` com o WhatsApp da empresa (DDI + DDD + número, só dígitos, ex.: `"5551999999999"`). O formulário de agendamento abre o WhatsApp com a mensagem pronta.

## Cores da marca

Laranja `#e8572a`, cinza `#4b525a` e preto `#070707`.
